How the implied value is worked out

One function scores every protocol. No name is ever special-cased.

implied = TVL × 0.22 × growth × maturity × chains
growth   = 1 + clamp(7d change, −50%, +150%) × 0.6
maturity = 0.55 + min(age, 1095 days) ÷ 1095 × 0.45   (age unknown: 365 days)
chains   = 1 + 0.04 × min(chains − 1, 4)

TVL is size today, seven-day growth is momentum, age with no token is how long the launch option has stayed open, and chain count is how widely the TVL is distributed. The watchlist is the floor, never the ceiling: this board adds the strongest pre-token protocols below the $50M floor, by TVL.

Implied value is this radar's own claim from the snapshot's figures. It does not predict whether or when a token is issued. Farm steps are a starting point: check the protocol's own page before moving funds, and never pay to claim.
